# Gemini Commit Analyzer Automation Tool

## 🚀 Overview

This tool automates the process of analyzing code changes between two Git commits, generating a detailed prompt for Google's Gemini Code Assist extension in Visual Studio Code, and then automatically injecting that prompt into the extension's chat window for analysis.

## ✨ Features

*   **Automated Git Diff:** Compares two specified commits in a local Git repository.
*   **Template-Driven Prompt:** Uses the vetted `commit_analysis_prompt.txt` instructions (or a custom template) to brief Gemini, keeping guidance stable and hallucination-free.
*   **Clipboard Integration:** Copies the generated prompt directly to the system clipboard.
*   **VS Code Automation:** Automatically launches Visual Studio Code, opens the Gemini Code Assist extension, focuses the chat input, pastes the prompt, and submits it.
*   **Fully Automated Workflow:** From execution to prompt submission, the process requires minimal manual intervention.
*   **Upper-Level Manager Script:** A dedicated `analysis_manager.py` helper validates your repo/commit inputs, writes the shared configuration, and now drives the entire automation (including the batch + AutoHotkey flow) with a single command.
*   **Context-Aware VS Code Session:** Files touched between both commits are opened automatically so Gemini’s context includes the exact artifacts being analyzed.

## 📋 Prerequisites

Before running this tool, ensure you have the following installed and configured on your Windows machine:

1.  **Git:**
    *   **Description:** Version control system required for analyzing code changes.
    *   **Installation:** Download from [git-scm.com](https://git-scm.com/download/win).
    *   **Verification:** Open Command Prompt and type `git --version`.

2.  **Python 3.x:**
    *   **Description:** Required to run the `commit_analyzer.py` script.
    *   **Installation:** Download from [python.org](https://www.python.org/downloads/windows/). Ensure you check "Add Python to PATH" during installation.
    *   **Verification:** Open Command Prompt and type `python --version`.

3.  **AutoHotkey v2.x:**
    *   **Description:** Powerful scripting language for Windows automation, used to control Visual Studio Code.
    *   **Installation:** Download from [autohotkey.com](https://www.autohotkey.com/download/). Choose the latest v2.x installer.
    *   **Verification:** After installation, open a command prompt and type `AutoHotkey.exe /?`. If it shows help, it's installed.

4.  **Visual Studio Code:**
    *   **Description:** Your code editor, where Gemini Code Assist runs.
    *   **Installation:** Download from [code.visualstudio.com](https://code.visualstudio.com/).
    *   **Verification:** Ensure you can launch VS Code.

5.  **Gemini Code Assist Extension for VS Code:**
    *   **Description:** The AI assistant that will analyze your code.
    *   **Installation:** Install directly from the VS Code Extensions Marketplace (search for "Gemini Code Assist").
    *   **Verification:** Ensure the Gemini extension is enabled and you can open its chat window.

## ⚙️ Configuration

This tool requires minor configuration to adapt to your environment and specific analysis needs.

1.  **`analysis_manager.py` (new!)**
    *   Provides a single entry point for setting the repository path and commit pair **and** launching the rest of the automation.
    *   Usage example:
        ```bash
        python analysis_manager.py --repo "D:/Repos/MyApp" --commit1 a1b2c3d --commit2 f4e5d6
        ```
    *   The script validates your git repo, confirms both commits exist, writes `analysis_config.json`, optionally pre-generates the prompt (`--generate-prompt`), and finally invokes `run_automation.bat` unless you pass `--skip-automation`.

2.  **`analysis_config.json`**
    *   Auto-generated by the manager. Stores `repo_path`, `commit1`, and `commit2` so batch/automation scripts can run non-interactively.
    *   Delete/regenerate it whenever you want to point the pipeline at a different repo or commit range.

3.  **`commit_analyzer.py` + `commit_analysis_prompt.txt`**
    *   The analyzer now reads the `commit_analysis_prompt.txt` template (or a path you pass via `--template`) and injects repo metadata, commit hashes, authors, branch, date range, file list, and the raw diff.
    *   Customize the template by editing the file or adding a new one with the same placeholder names (`{COMMIT_HASH_OLD}`, `{COMMIT_HASH_NEW}`, `{BRANCH_NAME}`, `{AUTHOR_NAME}`, `{DATE_RANGE}`, `{FILE_LIST}`, `{DIFF_CONTENT}`, `{REPO_NAME}`).
    *   The script still writes `changed_files.txt` so AutoHotkey can preload every touched file inside VS Code.

4.  **`gemini_automation.ahk`**
    *   Open `gemini_automation.ahk` in a text editor.
    *   Locate the `--- CONFIGURATION ---` section.
    *   **`vscode_path`**: **Crucial!** This must be the **absolute path** to your Visual Studio Code executable (`Code.exe`).
        *   **How to find it:** Right-click your VS Code shortcut (on Desktop, Start Menu, or Taskbar), select `Properties`, and copy the path from the `Target` field. Ensure the path includes `Code.exe`.
        ```autohotkey
        ; Example configuration:
        vscode_path = "C:\Users\YourUser\AppData\Local\Programs\Microsoft VS Code\Code.exe"
        ```

5.  **`run_automation.bat`**
    *   Open `run_automation.bat` in a text editor.
    *   Locate the line that executes the AutoHotkey script:
        ```batch
        "C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe" "D:\SWe\AI\Commit analyzer\Commit_analyzer\gemini_automation.ahk"
        ```
    *   **`AutoHotkey64.exe` Path**: If your AutoHotkey v2 installation is not in the default location (`C:\Program Files\AutoHotkey\v2\`), you will need to update the path to `AutoHotkey64.exe` in this line.

## 🚀 How to Use

1.  **Prepare your environment:** Close any running VS Code windows so the automation can start a fresh session.
2.  **Run the single entry point:** Execute `analysis_manager.py` with your repo/commit pair. Example:
    ```bash
    python analysis_manager.py --repo "D:/Repos/MyApp" --commit1 a1b2c3d --commit2 f4e5d6
    ```
    This command validates everything, updates `analysis_config.json`, (optionally) runs `commit_analyzer.py` if you add `--generate-prompt`, and then automatically launches `run_automation.bat` to drive VS Code/Gemini end-to-end. Pass `--skip-automation` if you only want to refresh the configuration without opening VS Code yet. Customize the prompt by editing `commit_analysis_prompt.txt` or passing `--template path/to/custom.txt` when calling `commit_analyzer.py` directly.

### Workflow

The `run_automation.bat` script (triggered automatically by `analysis_manager.py`) will orchestrate the following:
1.  Executes `commit_analyzer.py` (using the saved config) to capture the changed file list, load the static HTML template, and copy that template (with repo metadata injected) to your clipboard.
2.  Launches Visual Studio Code.
3.  Opens every file touched between the two commits so Gemini’s context window only includes relevant artifacts.
4.  Uses the VS Code Command Palette to explicitly focus the Gemini chat input field.
5.  Pastes the prepared HTML prompt into the Gemini chat.
6.  Sends the `Enter` key to submit the prompt for analysis. Gemini can now directly export the analysis as HTML with zero hallucinations because the prompt enforces factual constraints.

## ⚠️ Troubleshooting

*   **"ERROR: clip.exe not found." (from Python script):** Ensure your Windows installation is not corrupted. `clip.exe` is a standard Windows utility.
*   **VS Code doesn't open or isn't detected:** Double-check the `vscode_path` variable in `gemini_automation.ahk`. Ensure the path is exact.
*   **AutoHotkey script doesn't run or `AutoHotkey64.exe` not found:** Verify the path to `AutoHotkey64.exe` in `run_automation.bat` is correct for your AutoHotkey v2 installation.
*   **Prompt is not pasted/submitted:** If issues persist, there might be subtle timing differences on your system. You can try adjusting the `Sleep` durations in `gemini_automation.ahk` (e.g., increase `Sleep(5000)` to `Sleep(8000)`). Make small changes and test.
